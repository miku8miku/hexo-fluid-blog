> 本文介绍如何在中兴微设备上使用 alice-pusher-bot 实现短信转发功能，目前暂时仅支持钉钉推送。该版本为尝鲜测试版，可能存在些许bug，使用时请注意风险。

<!-- more -->

## 设备兼容性确认

首先确认设备是否支持此功能，理论上通杀，查看系统中是否存在 `/sbin/zte_mifi`。

![设备检查](https://fastly.jsdelivr.net/gh/miku8miku/images@main//202510211540463.png)

## 安装步骤

### STEP1. 下载所需文件

下载网盘中的两个文件到D盘：
[下载链接](https://www.123912.com/s/XGtA-dhL4)
（这边其实随便放，为了稳定以下都以D盘作为基准）。

### STEP2. 通过ADB推送文件

执行以下命令：

```bash
adb shell "mount -o remount,rw /" # 挂载目录
adb push "F:\alice-pusher-bot " /sbin/ # 推送软件
adb push "F:\strace " /sbin/
```

### STEP3. 设置执行权限

进入终端进行设置：

![](https://fastly.jsdelivr.net/gh/miku8miku/images@main//202510211538708.png)

执行以下命令：

```bash
chmod 777 /sbin/strace
chmod 777 /sbin/alice-pusher-bot
```

### STEP4. 配置钉钉机器人

去钉钉创建一个机器人，安全设置为自定义关键词 `pdu`（现已修改）。

![钉钉机器人配置](https://fastly.jsdelivr.net/gh/miku8miku/images@main//202510211539453.png)

记录下webhook的url，然后执行以下命令：

```bash
echo -e "sleep 20\n/sbin/alice-pusher-bot --mode=service_start --url=[钉钉机器人webhook地址] &" >> /etc/rc
```

然后重启设备即可。

## 技术说明

由于中兴微的硬件限制，实现此功能需要做相当多的内容和工作：

- 硬件不支持短信AT主动查询
- 空间剩余太小（500kb），还需塞进去1.5MB的程序（近三倍大小）
- 逆向破解中兴微的程序，扒取短信相关的函数调用
- HTTPS协议适配和移植
- 工具链C++支持移植
- 多线程进程隔离
- 软件进程优化
- 短信PDU编码解析
