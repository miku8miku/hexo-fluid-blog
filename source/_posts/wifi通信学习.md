> 本文详细介绍WiFi通信中的重要概念CPE和QCI，以及如何正确选择和设置IMEI号。对于从事通信设备开发或使用随身WiFi设备的用户来说，掌握这些知识有助于更好地理解和使用相关设备。

<!-- more -->

## CPE与QCI基本概念

### CPE (Customer Premises Equipment)

CPE 是 **Customer Premises Equipment** 的缩写，中文通常译作"用户驻地设备"或"客户终端设备"。这类设备通常部署在用户端，用于连接运营商网络和服务提供商的网络。

### QCI (QoS Class Identifier)

QCI 是 **QoS Class Identifier**（服务质量等级标识符）的缩写，主要用于 4G LTE 和 5G 网络中。QCI 为不同的数据业务分配优先级、延迟、丢包率等 QoS 参数，决定了一张 SIM 卡或一条承载（bearer）在空口和核心网里被"优待"到什么程度。

**重要原则：QCI 值越小，优先级越高。**

## IMEI选择的核心原则

在选择IMEI时，必须遵循以下核心原则：

**"必须选 15 位、能通过 Luhn 校验、且不在运营商 EIR 黑名单范围内的合法号段；除此之外，数字本身对网速没有任何加成。"**

## 合法IMEI的硬性指标

要选择一个合法的IMEI，必须满足以下三个硬性指标：

1. **总长度 15 位，全数字**
2. **第 15 位校验码必须能通过 Luhn 算法**（可使用在线生成器一键计算）
3. **前 8 位（TAC）要在 GSMA 官方号段表里**（可查询 <https://www.tacdb.com> 或工信部进网库）

{% note warning %}
不满足以上任意一条，基站直接回 Attach Reject #5（Illegal ME），连网都挂不上，更谈不上网速。
{% endnote %}

## IMEI选择思路与实操模板

| 场景 | 推荐做法 | 示例（仅格式演示） |
|---|---|---|
| ① 只想「能上网」 | 用旧手机原装 IMEI（拆下电池或拨 *#06# 抄） | 866655021234567 |
| ② 不想撞车 | 在原手机 IMEI 末 7 位 ±1 ~ ±3，重新算校验位 | 866655021234**568** |
| ③ 批量设备 | 向 GSMA 申请「小号段」或买正规 TAC（8 位）+ 自编 7 位流水号 | 8677xxxx00001 ~ 8677xxxx01000 |
| ④ 防止被定位 | 不同地区换不同末 7 位，但**同一台机器不要频繁改**；运营商后台 24 h 内多次异动会触发风控 |

## 绝对不要触碰的红线

在选择和设置IMEI时，必须避免以下几种情况：

1. **全 0 / 全 F / 14 位以下** → 100 % 拒绝入网
2. **复制别人"被封"的号** → 同黑名单库，秒拒
3. **直接抄网上"共享" IMEI 列表** → 撞车概率高，一旦同基站出现多台相同 IMEI，会被调度器集体降优先级
4. **自己乱编前 8 位** → 很大概率不在 GSMA 库，核心网直接判非法

## 不同芯片平台的写入方法

| 平台 | 常用指令/工具 | 备注 |
|---|---|---|
| 高通（QXDM/QPST） | 备份 QCN → 改串 → 写回 QCN | 需 9008 模式 |
| 中兴微 | 后台 `192.168.0.1` → 高级→其他 → AT 命令 | `AT+SPIMEI=0,"新IMEI"` |
| ASR/展锐 | AT 串口 `AT+SPIMEI=0,"新IMEI"` | 波特率 115200 |
| 海思 | `AT^IMEI="新IMEI"` | 需先解锁 NV 写权限 |

{% note info %}
写完后务必重启，再用 `AT+CGSN` 回读确认；最后一步上工信部官网或运营商 EIR 自助查询是否"已入库、无黑名单"。
{% endnote %}

## 总结

选择IMEI的核心原则是选择一个"合法身份证"：

**15 位 + Luhn 通过 + TAC 在库 + 不撞黑名单**，满足这四点即可；其余"吉祥数字、连号、所谓高网速号段"全是玄学，对速率毫无帮助。
